# PryIntegrador

## Presentación del jurado

Página estática (tema claro) para proyectar en el aula virtual durante la defensa del Proyecto Integrador — Universidad del Norte (Paraguay).

### GitHub Pages

Fuente publicada: carpeta `docs/` en `main` (copia de `presentacion-jurado/`).

URL esperada: https://arrieta32.github.io/PryIntegrador/

Si Pages aún no está activo: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/docs` → Save**.

### Abrir en local

```bash
# Desde la raíz del repo
python3 -m http.server 8080 --bind 127.0.0.1 --directory presentacion-jurado
# o: --directory docs
```

Luego abrir: [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

O abrir directamente `presentacion-jurado/index.html` / `docs/index.html` en el navegador.
